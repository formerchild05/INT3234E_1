### 2. Missing-value analysis

Notebook đã đọc `fundamentals.csv` và `securities.csv` nhưng chưa phân tích missing.

Tạo bảng:

```python
def missing_summary(df):
    result = pd.DataFrame({
        'missing_count': df.isna().sum(),
        'missing_percent': df.isna().mean() * 100
    })
    return result[result['missing_count'] > 0] \
        .sort_values('missing_count', ascending=False)

missing_summary(fund)
missing_summary(prices)
missing_summary(securities)
```

### 4. Cell “IQR” hiện chưa thực sự tính IQR

Cell 10 chỉ vẽ boxplot. Boxplot giúp nhìn outlier nhưng chưa tạo ngưỡng IQR.

Cần tính:

```python
grouped = COMP_2016.groupby('symbol')['return']

q1 = grouped.transform(lambda x: x.quantile(0.25))
q3 = grouped.transform(lambda x: x.quantile(0.75))
iqr = q3 - q1

COMP_2016['iqr_outlier'] = (
    (COMP_2016['return'] < q1 - 1.5 * iqr) |
    (COMP_2016['return'] > q3 + 1.5 * iqr)
)
```

Sau đó tổng hợp:

```python
COMP_2016.groupby('symbol')['iqr_outlier'].sum()
```

Trong dữ liệu 2016, IQR đánh dấu khoảng **9–27 dòng mỗi mã**, còn Z-score chỉ đánh dấu khoảng **2–6 dòng**. Đây là kết quả hay để nhận xét:

> IQR nhạy hơn Z-score vì return cổ phiếu không hoàn toàn tuân theo phân phối chuẩn.

### 7. Feature engineering

Thêm các biến:

```python
COMP['intraday_range'] = (
    (COMP['high'] - COMP['low']) / COMP['open']
)

COMP['log_volume'] = np.log1p(COMP['volume'])

COMP['volatility_20d'] = (
    COMP.groupby('symbol')['return']
    .transform(lambda x: x.rolling(20).std())
)

COMP['relative_volume'] = (
    COMP['volume'] /
    COMP.groupby('symbol')['volume']
        .transform(lambda x: x.rolling(20).mean())
)
```

Sau đó khám phá:

- Return và volume.
- Return và volatility.
- Outlier có đi cùng volume spike hay không.
- Ngành nào có volatility cao hơn.
